# ✨ Project Overview

> **ASHTASY BD** is a modern **E-Commerce Shopping Management System** developed using **PHP, MySQL, HTML, CSS, and JavaScript**.

The platform provides a complete shopping experience with dedicated dashboards for **Users** and **Administrators**. Customers can browse products, manage their carts, and place orders, while administrators can efficiently manage products, users, orders, and inventory.

# ⚙️ Installation Guide

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Ratul11012/webtech_project.git
```

---

### 2️⃣ Move Project

Move the project folder into:

```text
xampp/htdocs/
```

---

### 3️⃣ Create Database

```sql
CREATE DATABASE onlineshopdb;
```

---

### 4️⃣ Import Database

Import the SQL file located inside:

```text
db/
```

using **phpMyAdmin**.

---

### 5️⃣ Configure Database

```php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "onlineshopdb"
);
```

---

### 6️⃣ Run Project

Open your browser:

```
http://localhost/webtech_project/
```
